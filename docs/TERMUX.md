# بخش ترموکس — برنامه‌ی کاملاً آفلاین

این بخش برای وقتی است که نه کلودفلر در دسترس است، نه اینترنت، و تنها چیزی که
داری یک گوشی با ترموکس است. همه‌چیز از **همین پوشه** خوانده می‌شود.

```
python3 setup.py     # بررسی محیط + نصب termux-api + تست‌ها
python3 run.py       # → http://127.0.0.1:8000/
```

`run.py` هر آرگومانی جز `--open` را به `main.py` می‌دهد، پس `python3 main.py`
هم مستقیم کار می‌کند.

```
python3 run.py --open           اجرا + باز کردن مرورگر
python3 run.py --port 8080
python3 run.py --host 0.0.0.0   از گوشی دیگر در همان وای‌فای
python3 run.py --ask "کجام؟"
python3 run.py --repl
python3 run.py --status
python3 run.py --selftest
```

وابستگی خارجی ندارد: فقط کتابخانه‌ی استاندارد پایتون ۳.۹+. بدون npm، بدون pip،
بدون شبکه.

---

## ۱. آیا جی‌پی‌اس می‌گیرد؟

**بله، ولی نه مستقیم از پایتون.** اندروید به یک پروسه‌ی معمولی اجازه‌ی خواندن
موقعیت نمی‌دهد. مسیر واقعی این است:

```
Termux:API (اپ)  →  pkg install termux-api  →  اجازه‌ی Location
      →  termux-location -p gps -r once  →  JSON  →  termuxapp/gps.py
```

هر کدام از این حلقه‌ها می‌تواند نباشد. وقتی نباشد، برنامه عدد الکی نمی‌دهد؛
دلیل را با راهنمای فارسی برمی‌گرداند:

| `reason` | یعنی | چه کنی |
|---|---|---|
| `termux_api_missing` | افزونه نصب نیست | اپ Termux:API از F-Droid + `pkg install termux-api` |
| `permission_denied` | اجازه‌ی مکان داده نشده | در تنظیمات اندروید به Termux **و** Termux:API اجازه بده |
| `location_disabled` | جی‌پی‌اس گوشی خاموش است | از نوار اعلان روشنش کن |
| `no_fix` | `۰,۰` برگردانده = هنوز قفل نشده | برو فضای باز، چند لحظه صبر کن |
| `timeout` | در زمان مشخص قفل نشد | دوباره تلاش کن |
| `empty_response` | خروجی خالی | معمولاً یعنی سرویس مکان خاموش است |

> نکته: نسخه‌ی **گوگل‌پلی** اپ Termux:API با ترموکس جدید جور نیست. حتماً از
> F-Droid نصب کن.

`۰,۰` عمداً به‌عنوان موقعیت پذیرفته نمی‌شود — وگرنه کاربر را وسط خلیج گینه
نشان می‌داد.

### اگر جی‌پی‌اس نداری

می‌توانی مختصات را دستی بدهی؛ هم در تب «موقعیت» و هم در گفتگو:

```
> اینجا رو سیو کن به اسم خونه
< جی‌پی‌اس در دسترس نیست … مختصات را بفرست، مثلاً: 35.6997 51.3379
> 35.6997 51.3379
< ✅ «خانه» دستی ذخیره شد
```

---

## ۲. سیوِ مکان (نه اندازه‌گیری)

ایده این است: **یک بار** جایی که هستی را با اسم ذخیره کن، بعد هر وقت خواستی
فقط اسمش را بگو. لازم نیست مختصات را تکرار کنی.

| بگو | چه می‌شود |
|---|---|
| `اینجا رو سیو کن به اسم خونه` | موقعیت فعلی با نام «خانه» ذخیره می‌شود |
| `برم خونه` | جهت قطب‌نما + فاصله + تخمین زمان + لینک نقشه |
| `فاصله تا باشگاه چقدره` | فاصله‌ی مستقیم |
| `مکان‌های ذخیره شده` | فهرست همه |
| `نزدیک‌ترین مکان کدومه` | مرتب‌شده بر اساس فاصله از تو |
| `خونه رو پاک کن` | حذف |
| `برای خونه نام دیگر بگذار منزل` | نام مستعار |

جزئیات رفتاری که عمداً این‌طور طراحی شده:

- **سیوِ دوباره همان اسم، پین را جابه‌جا می‌کند**؛ «خانه ۲» ساخته نمی‌شود.
- **نام‌ها به شکل نوشتاری معیار ذخیره می‌شوند**: «خونه» به «خانه» تبدیل می‌شود
  تا «خونه» و «خانه» یک مکان باشند نه دو تا. هنگام جست‌وجو هر دو قبول است.
- «اینجا» به‌عنوان *نام* پذیرفته نمی‌شود؛ اگر بگویی «اینجا را ذخیره کن»
  اسم را می‌پرسد.
- اشتباه املایی هم پیدا می‌شود («خون» → «خونه») چون تطبیق فازی + آوایی است.

### چه چیزی واقعاً محاسبه می‌شود و چه چیزی نه

| | |
|---|---|
| ✅ فاصله‌ی خط مستقیم (haversine) | روی گوشی، بدون شبکه |
| ✅ جهت قطب‌نما (۸ جهت فارسی) + درجه | روی گوشی |
| ✅ تخمین زمان پیاده/دوچرخه/ماشین | سرعت ثابت ۴.۸/۱۵/۲۸ کیلومتر بر ساعت |
| ✅ لینک نقشه | فقط لینک؛ خود برنامه نقشه نمی‌گیرد |
| ❌ مسیر خیابان به خیابان | **نیاز به سرویس نقشه دارد — آفلاین ممکن نیست** |

فاصله‌ی گزارش‌شده خط مستقیم است. در شهر این می‌تواند ۲۰–۴۰٪ کمتر از مسیر
واقعی باشد. برنامه این را در پاسخ هم می‌گوید.

---

## ۳. هوش مصنوعی آفلاین — دقیقاً چیست

**صادقانه: این یک مدل زبانی بزرگ نیست.** روی گوشی، بدون اینترنت، مدل چند
گیگابایتی معنا ندارد. آنچه ساخته شده یک موتور سه‌لایه است:

1. **نرمال‌سازی فارسی** (`termuxapp/normalize.py`)
   - یکسان‌سازی حروف عربی/فارسی (ي→ی، ك→ک)، حذف اعراب، حذف tatweel
   - اعداد فارسی و عربی → ASCII
   - نیم‌فاصله → فاصله (برای جست‌وجو) و همزمان یک شکل *چسبیده* هم ساخته
     می‌شود تا الگوهای «مکان‌های» هم بخورند
   - گسترش محاوره: خونه→خانه، برم→بروم، سیو→ذخیره، میخوام→می‌خواهم
   - استِمر سبک (فقط جمع و پسوندهای بی‌ابهام؛ هرگز زیر ۳ حرف)

2. **تشخیص نیت** (`termuxapp/intents.py`)
   - ۲۵ نیت با الگوهای فارسی + استخراج جای‌نام (نام مکان، مقصد، نام مستعار)
   - هر پاسخ «امتیاز رتبه‌بندی» دارد که از `اولویت × اطمینان` می‌آید و
     **سقف ندارد** — سقف‌گذاری باعث می‌شد همه‌ی نیت‌های قوی با هم مساوی شوند
   - اگر الگو شکل را بگیرد ولی جای‌نام خالی بماند، امتیاز کم می‌شود و
     برنامه به‌جای حدس زدن، سؤال می‌پرسد

3. **بازیابی از پایگاه دانش** (`termuxapp/knowledge.py`)
   - BM25 روی `data/knowledge/*.json` (۱۹ مدخل)
   - تطبیق فازی: Levenshtein، Jaro-Winkler، Dice روی n-gram، و **کلید آوایی
     فارسی** که ز/ذ/ض/ظ و س/ث/ص و ه/ح و غ/ق را یکی می‌کند
   - بازخورد تو (لایک/دیس‌لایک) در `data/memory/feedback.jsonl` ذخیره و در
     رتبه‌بندی بعدی اثر می‌گذارد

### قانون «نمی‌سازم»

اگر هیچ‌کدام از این سه لایه جوابی پیدا نکند، پاسخ **«نمی‌دانم»** است، همراه با
نزدیک‌ترین گزینه‌ها. هیچ جواب ساختگی تولید نمی‌شود. این در تست هم قفل شده
(`test_unknown_question_is_not_answered_with_an_invention`).

## ۴. سرور لوکال و خواندن پوشه

`main.py` یک `ThreadingHTTPServer` بالا می‌آورد که همه‌چیز را از پوشه می‌خواند:

| مسیر | چه می‌دهد |
|---|---|
| `/` | رابط کاربری فارسی (RTL، موبایل‌اول) |
| `/api/status` | وضعیت جی‌پی‌اس، تعداد مکان‌ها، مدخل‌های دانش |
| `/api/gps`, `/api/gps/manual`, `/api/gps/watch` | موقعیت |
| `/api/places`, `/api/places/<name>`, `/api/route?to=` | مکان‌ها و مسیر |
| `/api/ask`, `/api/feedback` | دستیار |
| `/api/catalog`, `/api/knowledge` | کاتالوگ و پایگاه دانش |
| `/api/files?path=` + `/fs/…` | **مرورگر کل پوشه** |
| `/docs/…` | مستندات به‌صورت HTML |
| `/public/…` | خروجی بیلد بخش تایپ‌اسکریپت |

### امنیت

- پیش‌فرض `127.0.0.1`. برای دسترسی از گوشی دیگر: `--host 0.0.0.0`
- **بدون هدر CORS** — یعنی یک صفحه‌ی وب تصادفی نمی‌تواند موقعیت تو را بخواند
- هر مسیر کاربر از `paths.safe_resolve()` رد می‌شود؛ خروج از پوشه → `403`
- `CSP: script-src 'self'; frame-ancestors 'none'`، `X-Frame-Options: DENY`،
  `nosniff`، `no-referrer` روی هر پاسخ
- بدنه‌ی درخواست بالای ۲۵۶ کیلوبایت رد می‌شود
- خطاها بدون traceback به مرورگر برمی‌گردند

## ۵. اجرای تست‌ها روی گوشی

```
python3 setup.py
# یا
python3 run.py --selftest
# یا
python3 -m unittest discover -s tests -t .
```

هیچ بسته‌ی اضافی لازم نیست. GPS با یک runner جعلی که خروجی واقعی
`termux-location` را برمی‌گرداند تست می‌شود، پس شاخه‌های خطا دقیقاً مثل گوشی
اجرا می‌شوند.

## ۷. چیزهایی که عمداً اینجا نیست

- **نقشه‌ی آفلاین**: نیاز به داده‌ی چندصد‌مگابایتی OSM دارد.
- **اتصال به سرور ماینکرفت**: این برنامه آفلاین است؛ وضعیت زنده‌ی سرور را
  نمی‌گیرد و وانمود هم نمی‌کند که می‌گیرد.
- **مدل زبانی بزرگ**: روی گوشی بدون اینترنت معنا ندارد.
- **همگام‌سازی بین دستگاه‌ها**: داده روی همان گوشی می‌ماند.
